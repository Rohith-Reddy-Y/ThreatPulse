How to set up (free, 5 minutes)
  1. Create a free account at brevo.com.
  2. Brevo → Senders, Domains & Dedicated IPs → Senders → add the address mail should come from (e.g. your Gmail) and click the link Brevo emails you.
  3. Brevo → SMTP & API → API Keys → generate a key.
  4. Render → threatpulse → Environment: add BREVO_API_KEY (the key) and MAIL_FROM (the verified sender). Save — Render redeploys.
  5. If the test says the IP is unrecognised: Brevo → Security → Authorised IPs → turn off IP blocking (Render's IPs change).
